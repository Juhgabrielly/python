# Estudando Python

Lista de exercícios de Python resolvida em aula do SESI SENAI no curso Técnico em Desenvolvimento de Sistemas.

## Tecnologias

- Python
- VsCode

## Exercícios

### Exemplos da aula

- `soma.py` - Soma de dois números
- `condicional.py` - Verificação de número par ou ímpar
- `for.py` - Números de 1 a 100

### Lista de exercícios

- `exercicio01_media.py` - Média de três números
- `exercicio02_temperatura.py` - Conversão de Celsius para Fahrenheit
- `exercicio03_par_impar.py` - Verificação de número par ou ímpar
- `exercicio04_fatorial.py` - Cálculo de fatorial
- `exercicio05_bissexto.py` - Verificação de ano bissexto
- `exercicio06_positivo_negativo.py` - Verificação de número positivo, negativo ou zero
- `exercicio07_maior_numero.py` - Comparação de dois números
- `exercicio08_idade.py` - Verificação de maioridade
- `exercicio09_triangulo.py` - Classificação de triângulos
